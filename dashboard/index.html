THE MISSING QUESTION

Authentication is not the end of authorization.

GATE complements your identity provider and policy engine. It answers whether a delegated authority path is still valid according to the evidence available to the network.

01 ↗

Know when delegation changes

Accept signed ACTIVE and REVOKED authority events. Re-check rather than assuming a previously valid token proves ongoing authority.

02 ◇

Preserve valid alternate paths

A revoked route need not eliminate independently authorized paths. GATE resolves the graph rather than checking a single token in isolation.

03 ⊘

Fail closed when evidence is missing

Distinguish known invalid authority from UNKNOWN or stale evidence. No fresh, established authority means no protected effect.

Node.js · GATE Developer Preview
# Install from the public npm registry
npm install @gate-avn/sdk@0.1.0-dev.4

// Before a protected action
import { GateClient } from '@gate-avn/sdk';

const gate = new GateClient({
  endpoint: process.env.GATE_URL,
  apiKey: process.env.GATE_API_KEY
});

const decision = await gate.verify({
  principal: 'user:owner',
  actor: 'agent:assistant',
  consistency: 'bounded'
});

if (decision.decision !== 'ALLOW') {
  throw new Error('authority_not_established');
}

// Then apply your own action policy before the effect.
