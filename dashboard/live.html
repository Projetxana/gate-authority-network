Run one real verification against the managed network. This consumes one verification from the monthly Free quota.

A fresh project should fail closed with DENY / no_authority_path.

Confirm the live project first.
import { GateClient } from '@gate-avn/sdk';

const gate = new GateClient({
  endpoint: process.env.GATE_URL,
  apiKey: process.env.GATE_API_KEY
});

const result = await gate.verify({
  principal: 'user:alice',
  actor: 'agent:procurement@company-c',
  consistency: 'bounded'
});

console.log(result.authority, result.decision);

A fresh live project has no preloaded authority graph. Do not expect an arbitrary principal/actor pair to return ALLOW.
